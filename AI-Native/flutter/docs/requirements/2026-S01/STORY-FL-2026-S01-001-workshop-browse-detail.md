# STORY-FL-2026-S01-001 · 01 浏览活动与查看详情

迭代 `2026-S01` · Android / iOS · 简体中文

## 用户目标

作为想参加周末手作活动的体验者，我希望浏览近期场次、查看活动时间、地点和剩余名额，并在返回时接着浏览，以便决定是否参加。

## 输入与依赖

- 需求来源为周末工坊预约 v1.0，验收沿用产品编号 A1–A4。 [产品需求](/Users/laopi/Desktop/Test/周末工坊预约/产品需求.md) · [交互与视觉](/Users/laopi/Desktop/Test/周末工坊预约/交互与视觉.md) · [联调说明](/Users/laopi/Desktop/Test/周末工坊预约/联调说明.md)
- 依赖 v1.0.0 模拟服务及固定的五条活动。后端 Story 摘要待提供，当前由 PRD 和契约支撑。首载空数组、乱序响应等场景可通过符合契约的测试数据验证。
- 本卡可独立验收。第 02 卡启用 P2 的预约提交，第 03 卡接入底栏「我的预约」和 P3 → P2 返回链路。

## 验收标准

| AC | Given 前提 | When 操作 | Then 可观察结果 | 页面 |
|---|---|---|---|---|
| A1 | 固定演练数据，进入发现 | 首载并滚动至页尾，或在首屏不足一屏时点击「加载更多」 | 首载有加载提示。首批依次为纸上造景、手捏陶杯、手工装帧，展示活动日期、时段、地点及余位或预约状态。已有预约时同一活动行同时显示「已预约」和最新余位。追加时仅页尾显示加载，随后新增草木拓印、木匙打磨。滚动触发去重，`nextPage=null` 后停止请求。首载成功且 `items` 为空时显示「暂无活动」 | P1 |
| A2 | 已在发现加载第二页 | 点击木匙打磨整行，查看后返回，再下拉刷新 | 使用活动 ID `w05` 读取详情，展示标题、日期、时间、地点、名额与介绍，详情隐藏底栏；满额行也可打开详情。用页面返回、Android 系统返回或 iOS 返回手势回到来源，发现恢复已加载页和滚动位置；刷新成功以第一页替换旧页。只有 ID 也可读取详情，直接打开且无来源时返回发现 | P1、P2 |
| A3 | 首载、刷新或追加遇到网络失败，或有旧分页请求在途 | 触发失败，恢复网络后重试，或刷新成功后收到旧页响应 | 首载显示「加载失败 / 重试」；刷新失败保留原列表并提示「刷新失败」；追加失败保留原列表，页尾可重试原页。恢复后按当前请求更新，过期分页响应无法覆盖、追加或重复现有记录 | P1 |
| A4 | 详情 ID 不存在，或详情加载中、网络失败；在窄屏或大字号下打开页面 | 等待详情响应，尝试返回、重试或滚动 | 加载时可返回。404 显示「活动不存在」和返回入口，网络错误提供重试。大字号下标题可以换行，详情可滚动，核心操作可触达 | P1、P2 |

展示时间固定按东八区，场次无过期判定。活动按开始时间升序。状态按 `myReservationId` 和 `remaining` 展示，已有预约优先于「已满额」，余位取接口的 `remaining`。

交互说明建议 P1 使用 `/discover`，P2 使用 `/workshops/:workshopId`，以可从两个一级页进入并返回来源为验收行为。

## 本卡 API 范围

| AC | operationId | Method | Path | 说明 |
|---|---|---|---|---|
| A1、A2、A3 | `listWorkshops` | GET | `/workshops` | `page=1&pageSize=3` 首载和刷新，追加使用 `nextPage`，HTTP 200 读取 `items` 与 `nextPage` |
| A2、A4 | `getWorkshop` | GET | `/workshops/{workshopId}` | 使用字符串活动 ID，HTTP 200 展示详情，404 / `NOT_FOUND` 显示「活动不存在」 |
